## 🚗 자율주행 *(개인 진행중 — 팀 제출본과 별개의 개인 PC prototype)*

### ERP42 자율주행 (2025 대학생 창작자동차 경진대회)
ERP42 차량 플랫폼 · 2~3인 팀(팀 MTP, 충남대) · source-level prototype
**주요 담당:** Waypoint pathtracking · lane/path Controller 중재 · LiDAR 클러스터링(실험)
`Waypoint Pathtracking` `lane/path arbitration` `LiDAR 클러스터링`

- **목적:** 예선 10분·본선 15분 단일 주행에서 차선 유지·장애물 회피·GPS 음영구간·교차로·주차를 모두 통과하는 대회 미션.
- **본인 해결:** perception 유무와 무관하게 도는 waypoint pathtracking baseline(heading error 비례 조향 + 직전 스텝 blending)과, lane/path 2채널을 우선순위·freshness timeout으로 중재하고 유효 입력이 없으면 full-brake하는 Controller Node를 설계. LiDAR 포인트클라우드 클러스터링(장애물 인식)도 담당.
- **구현 범위·상태:** 팀 회고 기준 baseline 주행으로 완주. 실 주행 rosbag을 직접 열어 녹화된 토픽을 확인하고 위치추정 코드의 숨은 의존성까지 점검(실제 replay는 도구 미설치로 미시도)했으며, LiDAR 클러스터링은 런타임 결함·다운스트림 미연결을 스스로 발견해 "실험 코드"로 정직히 분류. Controller Node는 source-level(미설치), 대회 정량 지표는 로그 부재로 비공개.

### 🚨 제조업 공장 산업안전 AMR 순찰로봇 및 관제 시스템 
AMR(자율이동로봇) 2대 · 천장 웹캠 2대 · 3인 팀 · 2차(26.07.01~26.07.14)
**주요 담당:** 우선순위 선점 FSM · 쓰러짐 판정(v13) · 메시지 의미별 QoS 설계
`우선순위 선점 FSM` `쓰러짐 판정` `QoS 3분리`

- **목적:** 천장 웹캠이 쓰러짐·안전모 미착용·무단침입을 감지하면 가장 가까운 AMR을 골라 출동시키는 안전관제 시스템.
- **본인 해결:** 응급>안전모>순찰 우선순위로 현재 작업을 선점하는 FSM과, 사람이 쓰러지는 순간 발생하던 응급-해제 채터링을 해제 방향에만 디바운스를 걸어 막는 로직을 설계. 쓰러짐 판정은 "누우면 머리가 발 위에 있다"는 역산 가정이 깨지는 머리 높이 단일 신호에서 몸통 각도 주지표+다리 거부권 방식으로 재설계했고, 메시지 의미별 QoS 분리와 timestamp stale 필터로 처리 끝난 옛 명령이 재출동을 일으키지 않도록 설계.
- **구현 범위·상태:** 3인 팀이 패키지 3개(감지/관제/DB)로 분담(본인=관제·안전 판정 로직). 공개 repo 없음, case study 정리 중.

### ☕ 협동로봇 핸드드립 커피 자동화
Doosan M0609 협동로봇 · 5인 팀 · 두산로보틱스 교육과정  · 3차(26.07.15~26.07.29)
**주요 담당:** 그리퍼(로봇 손) 파지 판정 · 통신 워치독 · 단계별 복구 FSM
`bit/effort/position 교차판정` `fail-closed watchdog`

- **목적:** 비전 센서 없이 원두 계량부터 나선형 드립까지 5단계 추출 공정을 로봇 제어만으로 자동화.
- **본인 해결:** 카메라가 없어 성공·실패를 힘·접점·통신 신호로만 판정 — grip 비트가 안 떠도 접촉 흔적(effort/position)이 있으면 "판정 불가"로 분리하는 3값 파지 판정과 단계별 복구 FSM 구현. 20Hz(50ms) fail-closed watchdog이 그리퍼 상태를 상시 확인하다 1초 이상 신호가 끊기면 즉시 정지, 재시도/중단은 작업자가 선택. 반복 파지 중 rclpy 로거 severity 캐시 버그로 공정 전체가 죽던 문제도 로그 호출을 분기별로 분리해 해결(프레임워크 내부 동작까지 추적).
- **구현 범위·상태:** 팀 제출 완료작 — 통신 워치독·복구 FSM은 제출본, 3값 파지 판정·pytest 7종(~947 LOC)은 병행 개인본(테스트는 구성 확인, 실행 재현은 미확인).

### 🦾 VLA 기반 자연어 Pick & Place 시스템 - 환경 인식 및 정적장애물 회피
Doosan M0609 협동로봇 · 팀 프로젝트  · 4차(26.07.30~26.08.12)
**주요 담당:** 판단 계층·안전 계층 통합, 인지 실패 감지 게이트
`FSM` `안전 게이트` `LLM function calling(GPT-5-mini)`

- **목적:** "빨간 컵을 상자로 옮겨줘" 같은 자연어 지시를 로봇이 수행.
- **본인 해결:** 판단 LLM 계층(구조화된 장면 정보로 결정)과 안전 계층(pick FSM)이 각자 로봇을 직접 제어하던 구조를 통합 — 제어 권한을 안전 계층 하나로 좁히고, 인지 파이프라인 상태를 모션 계획 성공 여부와 별도로 확인하는 게이트를 구현("인식은 죽었는데 계획만 성공"하는 조용한 실패를 감지하도록 설계). 재계획 로직은 ON/OFF를 파일까지 분리한 대조군 A/B로 검증(무조건 교체 시 오히려 도착 실패 → 동일 경로 교체를 생략하도록 수정).
- **구현 범위·상태:** 판단 계층 설계는 팀, 통합·안전 게이트는 본인 담당. 실제 장애물 투입 회피와 전체 pick-to-place 실물 검증은 미완료.
