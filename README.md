## 🚗 자율주행 *(개인 진행중 — 팀 제출본과 별개의 개인 PC prototype)*

### ERP42 자율주행 (2025 대학생 창작자동차 경진대회)
ERP42 차량 플랫폼 · 2~3인 팀(팀 MTP, 충남대) · source-level prototype
**주요 담당:** LiDAR 클러스터링 실험 코드, lane/path 2채널 Controller prototype
`LiDAR 클러스터링` `Path Tracking`

예선 10분·본선 15분의 단일 주행에서 차선 유지·장애물 회피·GPS 음영구간·교차로·주차를 모두 통과해야 하는 대회 미션에서, 저는 LiDAR(레이저 기반 거리 센서) 포인트클라우드를 물체 단위로 묶어내는 클러스터링 실험 코드와, 차선·경로 두 입력 중 유효한 쪽을 선택하고 입력이 없으면 제동하는 Controller Node를 담당했습니다. 이 Controller는 lane/path 2채널까지 다뤘고, 팀 최종 통합본에는 포함되지 않은 source-level prototype 단계로 남아 있습니다.

### 🚨 제조업 공장 산업안전 AMR 순찰로봇 및 관제 시스템 
AMR(자율이동로봇) 2대 · 천장 웹캠 2대 · 3인 팀 · 2차(26.07.01~26.07.14)
**주요 담당:** 카메라→실제 좌표 변환 시 신뢰도 가중 결합 로직
`가중최소자승(민감도 가중)` `좌표 변환`

천장 웹캠이 작업자의 쓰러짐·안전모 미착용·무단침입을 감지하면, 관제 시스템이 가장 가까운 AMR을 골라 현장에 출동시키는 안전관제 시스템입니다. 3인 팀이 패키지 3개(감지/관제/DB)로 역할을 나눠 개발했고, 저는 카메라로 관측한 높이값을 실제 바닥 좌표(map 좌표)로 옮기는 과정에서, 여러 관측치 중 값이 흔들리기 쉬운 쪽은 덜 반영하도록 민감도 기반 가중치를 결합하는 로직(가중최소자승)을 직접 설계했습니다.

### ☕ 협동로봇 핸드드립 커피 자동화
Doosan M0609 협동로봇 · 5인 팀 · 두산로보틱스 교육과정  · 3차(26.07.15~26.07.29)
**주요 담당:** 그리퍼(로봇 손) 파지 판정 · 통신 워치독 · 단계별 복구 FSM
`bit/effort/position 교차판정` `fail-closed watchdog`

비전 센서 없이 원두 계량부터 나선형 드립까지 5단계 커피 추출 공정을 로봇 제어만으로 자동화한 프로젝트입니다. 카메라가 없어 성공·실패를 힘·접점·통신 신호로만 판정해야 했는데, 저는 bit·effort·position 세 신호를 교차 확인하는 파지 판정과 단계별 복구 FSM(로봇 작업 단계를 관리하는 상태머신)을 구현했습니다. 20Hz(50ms 주기) watchdog(신호가 끊겼는지 감시하는 장치)이 그리퍼 상태를 상시 확인하다 1초 이상 신호가 끊기면 로봇을 정지시키고, 실패 후 재시도할지 중단할지는 작업자가 선택하도록 설계했습니다.

### 🦾 VLA 기반 자연어 Pick & Place 시스템 - 환경 인식 및 정적장애물 회피
Doosan M0609 협동로봇 · 팀 프로젝트  · 4차(26.07.30~26.08.12)
**주요 담당:** 판단 계층·안전 계층 통합, 인지 실패 감지 게이트
`FSM` `안전 게이트` `LLM function calling(GPT-5-mini)`

"빨간 컵을 상자로 옮겨줘" 같은 자연어 지시를 로봇이 수행하는 시스템입니다. 어떤 물체를 어디로 옮길지 판단하는 LLM 계층(카메라 사진이 아니라 구조화된 장면 정보를 받아 결정)과 실제 모션·그리퍼를 움직이는 안전 계층(pick FSM)이 원래 각자 로봇을 직접 제어하던 구조였는데, 저는 이 둘을 통합하면서 로봇 제어 권한을 안전 계층 하나로 좁히고, 인지 파이프라인 상태를 모션 계획 성공 여부와 별도로 확인하는 게이트를 적용해 "인식은 죽었는데 계획만 성공"하는 조용한 실패를 구조적으로 줄였습니다. 다만 실제 장애물 투입 회피와 전체 pick-to-place 실물 검증은 아직 완료되지 않았습니다.
