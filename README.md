## 🚗 자율주행 *(개인 진행중 — 팀 제출본과 별개의 개인 PC prototype)*

### ERP42 자율주행 (2025 대학생 창작자동차 경진대회)
ERP42 차량 플랫폼 · 2~3인 팀(팀 MTP, 충남대) · source-level prototype
**주요 담당:** LiDAR 클러스터링 실험 코드, lane/path 2채널 Controller prototype
`LiDAR 클러스터링` `Path Tracking`

- **목적:** 예선 10분·본선 15분 단일 주행에서 차선 유지·장애물 회피·GPS 음영구간·교차로·주차를 모두 통과하는 대회 미션.
- **본인 해결:** LiDAR 포인트클라우드를 물체 단위로 묶는 클러스터링 실험 코드, lane/path 두 입력 중 유효한 쪽을 선택하고 입력이 없으면 제동하는 Controller Node.
- **결과·검증:** lane/path 2채널까지 구현. 팀 최종 통합본에는 미포함된 source-level prototype 단계.

### 🚨 제조업 공장 산업안전 AMR 순찰로봇 및 관제 시스템 
AMR(자율이동로봇) 2대 · 천장 웹캠 2대 · 3인 팀 · 2차(26.07.01~26.07.14)
**주요 담당:** 카메라→실제 좌표 변환 시 신뢰도 가중 결합 로직

### ☕ 협동로봇 핸드드립 커피 자동화
Doosan M0609 협동로봇 · 5인 팀 · 두산로보틱스 교육과정  · 3차(26.07.15~26.07.29)
**주요 담당:** 그리퍼(로봇 손) 파지 판정 · 통신 워치독 · 단계별 복구 FSM
`bit/effort/position 교차판정` `fail-closed watchdog`

- **목적:** 비전 센서 없이 원두 계량부터 나선형 드립까지 5단계 추출 공정을 로봇 제어만으로 자동화.
- **본인 해결:** 카메라가 없어 성공·실패를 힘·접점·통신 신호로만 판정 — bit·effort·position 세 신호를 교차 확인하는 파지 판정과 단계별 복구 FSM 구현. 20Hz(50ms) watchdog이 1초 이상 신호가 끊기면 로봇 정지, 재시도/중단은 작업자가 선택.
- **결과·검증:** 팀 제출 완료작(파지 판정·복구 로직은 본인 담당).

### 🦾 VLA 기반 자연어 Pick & Place 시스템 - 환경 인식 및 정적장애물 회피
Doosan M0609 협동로봇 · 팀 프로젝트  · 4차(26.07.30~26.08.12)
**주요 담당:** 판단 계층·안전 계층 통합, 인지 실패 감지 게이트
`FSM` `안전 게이트` `LLM function calling(GPT-5-mini)`

- **목적:** "빨간 컵을 상자로 옮겨줘" 같은 자연어 지시를 로봇이 수행.
- **본인 해결:** 판단 LLM 계층(구조화된 장면 정보로 결정)과 안전 계층(pick FSM)이 각자 로봇을 직접 제어하던 구조를 통합 — 제어 권한을 안전 계층 하나로 좁히고, 인지 파이프라인 상태를 모션 계획 성공 여부와 별도로 확인하는 게이트를 적용해 "인식은 죽었는데 계획만 성공"하는 조용한 실패를 차단.
- **결과·검증:** 판단 계층 설계는 팀, 통합·안전 게이트는 본인 담당. 실제 장애물 투입 회피와 전체 pick-to-place 실물 검증은 미완료.
